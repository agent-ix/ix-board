# SR-6123: SWM-301 team exporter series

## Summary

Ticket: SWM-301. Code review, with the Rust lane, of agent-ix/ix-board#99 at
f3e6e528723ac4aea38c581e35e1f049a6150800 (rebase of 5ba6b2e; `git range-diff`
shows the only change is that the Cargo.toml and Cargo.lock version hunks
dropped out). The PR build was run on a loopback port against a copy of the live
exporter state on draco. For team QSL only `ix_team_stage_oldest_age_seconds`
produced a sample, and every stage read 0 while no assignment evidence existed.
The other four series stayed absent. Their causes are unchanged by this PR.

## Verdict

**FAIL** - four of the five series stay absent for QSL and the fifth reports an
unsupported zero.

Gates at this head's sources: `cargo fmt --check` passed, `cargo clippy
--all-targets -- -D warnings` passed, `cargo test --lib team_metrics` passed
(55 passed, 2 ignored). The worktree held uncommitted version-bump edits to
manifests during the gate run; no source file differed from the head. No CI
workflow file changed.
